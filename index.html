常见问题

Windows 弹出「已保护你的电脑」，怎么继续？

这是 SmartScreen 在提示安装包没有公开 CA 的签名与信誉，不是病毒告警。安装包使用项目自签名证书（CN=鎏灏智能中枢, O=LiuHao AI OS, C=CN；指纹以 AE398F09 开头）：未导入信任的机器会把它当作「未知发布者」，这是自签名证书的正常现象。

  1. 看到蓝色窗口「Windows 已保护你的电脑」时，点左侧的 「更多信息」；
  2. 窗口下方出现「应用：LiuHao-Setup-0.1.1.exe」和 「仍要运行」，点它；
  3. 进入安装向导后按提示操作；默认安装路径不需要管理员权限，不会弹 UAC。

关于签名：双击随包提供的 信任签名证书.cmd（需与 trust-liuhao-signing.ps1、LiuHao-CodeSigning.cer 放在同一目录），即可把证书导入当前 Windows 用户的受信任存储，不需要管理员。导入后右键安装包 → 属性 →「数字签名」能看到真实签名者，Get-AuthenticodeSignature 返回 Valid。

但按微软口径，自签名证书不等于无警告：SmartScreen 的云端信誉判断不受本机信任库影响，从网上下载仍可能弹出提示，这与信任脚本是否装好无关，也不代表安装包已经通过发布验证。

信任脚本失败怎么办：窗口会打印中文原因。常见情况是 .cer 不在同一目录或文件损坏、证书存储被组策略锁定、PowerShell 执行策略拦截脚本。若要写机器级存储（对所有用户生效），需右键「以管理员身份运行」并加 -AllUsers；不是管理员时脚本会报错退出（退出码 2），此时去掉该参数只信任当前用户即可。

如果点「更多信息」后没有「仍要运行」，或提示「已被组织阻止」，说明文件可能被改动或来源不可信：请停止安装，重新从本页下载，并核对 SHA256。

怎么验证安装包签名？

两种方式，任选一种：

  • 图形界面：右键 LiuHao-Setup-0.1.1.exe → 属性 →「数字签名」→ 选中签名条目 →「详细信息」，签名者应显示「鎏灏智能中枢」。
  • 命令行：在 PowerShell 里运行 Get-AuthenticodeSignature "D:\LiuHao-Setup-0.1.1.exe" | Format-List Status, SignerCertificate。

未导入信任时，Status 可能是 UnknownError（根证书不受信任）；成功运行随包的 信任签名证书.cmd 后应为 Valid。若仍是 UnknownError，说明导入未生效，请查看脚本窗口里的原因。证书主体为 CN=鎏灏智能中枢, O=LiuHao AI OS, C=CN，SHA-1 指纹以 AE398F09 开头，应与随包的 LiuHao-CodeSigning.cer 一致。签名有效不等于文件来源可信，下载后仍请核对本页的 SHA256。

升级链路现在是什么状态？

信任链已就位。升级清单采用签名发布，验签通过；清单内容被篡改、或与升级包不匹配时会被拒绝，不会静默生效。

升级清单与升级包托管在本站 updates/ 目录，由升级线统一上传与签发。页面只说明链路状态，不承诺自动升级的开放时间；需要升级时，直接用本页的安装包覆盖安装即可。

不要手工改 updates/LIUHAO_RELEASE.json：它已被签名，改动任意一个字节都会验签失败。

装完打不开、或者打开没反应怎么办？

按顺序排查，多数情况是端口被占用或窗口只是隐藏了：

  • 先看任务栏右下角托盘：关掉状态窗口只是隐藏到托盘，网关仍在运行；双击桌面「LiuHao AI OS · 鎏灏智能中枢」快捷方式可重新打开窗口。
  • 如果提示端口被占用，窗口会说明被谁占用：关掉占用程序再启动，或在首启向导 / 启动入口里换一个空闲端口。
  • 需要看命令行输出：在程序目录运行 LiuHao.bat --console，会打印启动过程与错误原因。
  • WebView2 缺失时程序会提示，可先装 WebView2，或用托盘菜单「在浏览器中打开」进入控制台。
  • 仍然不行：开始菜单 →「LiuHao AI OS · 鎏灏智能中枢」→「收集诊断信息（离线）」，双击生成脱敏诊断包（服务未启动也能用），把它发给支持人员。
我填的 API Key 存在哪里？会被上传吗？

只存在本机。API Key 用 AES-256-GCM 加密后保存在你的数据目录（默认 D:\LiuHaoData\data），不会上传到任何服务器，也不会以明文写进配置文件。

备份时把整个数据目录复制走即可，但必须同时复制 data\model_config.key 与 data\model_registry.sqlite3：少一个，已保存的 Key 就解不开。卸载时默认保留数据，只有连续两次确认才会删除。

对话、知识库、审计记录是本地明文 SQLite 文件，依靠 Windows 账号权限保护；多人共用或设备可能丢失时，建议开启 BitLocker。

下载下来的文件和页面上的 SHA256 不一致？

说明文件在传输或转存过程中被改动过，不要安装。请在 PowerShell 里重新计算并比对：

Get-FileHash .\LiuHao-Setup-0.1.1.exe -Algorithm SHA256

一致才继续；不一致请删掉文件，重新从本页下载。
